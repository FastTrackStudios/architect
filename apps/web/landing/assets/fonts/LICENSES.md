# Fonts

Both fonts are subset to Latin (WOFF2) for this page.

- `archivo.woff2`: Archivo (variable: `wght` 100–900, `wdth` 62–125) by Omnibus-Type, SIL Open Font License 1.1 (`Archivo-OFL.txt`). Source: github.com/google/fonts `ofl/archivo`.
- `osifont.woff2`: osifont, ISO 3098 technical lettering, by hikikomori82 and contributors, GNU LGPL v3 with the font exception (`osifont-lgpl3fe.ttf`). Source: github.com/hikikomori82/osifont.
