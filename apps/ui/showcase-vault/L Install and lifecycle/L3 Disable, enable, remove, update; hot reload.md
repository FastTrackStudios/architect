# L3 Disable, enable, remove, update; hot reload

An extension's lifecycle, and a development copy reloaded on save.

**Stands in for:** Obsidian's plugin toggles, Hot-Reload.

## Try

1. Open Settings › Extensions, turn a showcase extension off and on.
2. Edit one of its files and save.

## You should see

Its actions and contributions leave and come back; the saved change shows at once.

**Example:** Every showcase extension (they run as development copies).

Its status on desktop, web and iOS is in [[Showcase]].
