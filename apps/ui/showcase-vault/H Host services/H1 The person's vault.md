# H1 The person's vault

List, read, create, edit, rename, move and delete notes through the document API.

**Stands in for:** Every plugin that touches files.

## Try

1. Run `Templater-lite: new from template`.

## You should see

A new note in the vault. Today the document API acts on an in-memory sample store (#706); `VAULT_*` actions reach the vault.

**Example:** Templater-lite.
