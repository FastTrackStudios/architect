# R4 A WASI component installed at run time

A component built for `wasm32-wasip2`, run in Wasmtime (Pulley on iOS, jco in browsers).

**Stands in for:** Plugins with heavy compute: OCR, git, embeddings.

## Try

1. Needs a build with `wasi` (#707). With one, open the WASI Counter's tab.

## You should see

A counter that counts on click, its state in the component.

**Example:** WASI Counter (`apps/sandbox/wasi-counter`).

Its status on desktop, web and iOS is in [[Showcase]].
