# R2 A Luau script installed at run time

A Luau extension loaded from a folder: its scripts are actions, reloaded when saved.

**Stands in for:** Templater user scripts, QuickAdd macros.

## Try

1. Open ⌘K and run `Templater-lite: insert date`.
2. Edit its script in `examples/showcase/templater-lite` and save: run it again.

## You should see

The date inserted at the cursor; after a save, the new behaviour with no restart.

**Example:** Templater-lite.

Its status on desktop, web and iOS is in [[Showcase]].
