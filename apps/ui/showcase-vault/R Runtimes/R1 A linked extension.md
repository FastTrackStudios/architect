# R1 A linked extension

An extension compiled into the distribution: its crate implements one trait and runs in the app's process.

**Stands in for:** Every Obsidian core plugin; Studio's setlists.

## Try

1. Open ⌘K and type `Calendar`, `Tasks` or `Setlists`.
2. Open Settings › Extensions: the first-party extensions are listed as built in.

## You should see

Their actions in ⌘K and their views in the Vault's tabs, with no install step.

**Example:** Setlist viewer, Tasks, Calendar (the standard distribution).

Its status on desktop, web and iOS is in [[Showcase]].
