# C2 Toolbars and status items

Toolbars with toggle state, status items, the phone bar.

**Stands in for:** Editing Toolbar, Commander, the status bar.

## Try

1. Open a note and type in it: the Outline toolbar shows on the Typing Toolbar.
2. Look at the status row for the Toolbar sampler's item.

## You should see

Buttons that run actions, a toggle that shows whether it is on, a status item with text.

**Example:** Toolbar sampler, Outline.

Its status on desktop, web and iOS is in [[Showcase]].
