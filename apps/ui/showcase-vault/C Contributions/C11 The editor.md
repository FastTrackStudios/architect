# C11 The editor

Commands on the selection, keymaps by node, decorations and widgets, slash rows.

**Stands in for:** Advanced Tables, Outliner, Editing Toolbar.

## Try

1. Open [[Tables and lists]]. In a list, press Tab and Shift-Tab; in a table, Tab between cells.
2. Type `/` and pick Table.

## You should see

Items indent and outdent, Tab walks the cells and adds a row past the last; each change is one undo step.

**Example:** Outline (`apps/sandbox/extensions/outline`).

Its status on desktop, web and iOS is in [[Showcase]].
