# C1 Actions everywhere

An extension's actions in ⌘K, on keys, on the CLI, over MCP and on the control socket.

**Stands in for:** Commander, every plugin's commands.

## Try

1. Open ⌘K and type `Showcase`.
2. On the desk: `architect-desktop actions list | grep SHOWCASE`.

## You should see

The showcase extensions' actions, runnable from each place.

**Example:** Templater-lite.

Its status on desktop, web and iOS is in [[Showcase]].
