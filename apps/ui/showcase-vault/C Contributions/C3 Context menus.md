# C3 Context menus

Rows in the file, editor and row menus, and a menu at a point.

**Stands in for:** File-menu plugins, Commander.

## Try

1. Right-click a file in the navigator.
2. Run `Toolbar sampler: menu here`.

## You should see

The sampler's rows in the file menu; a menu opened at the pointer.

**Example:** Toolbar sampler.

Its status on desktop, web and iOS is in [[Showcase]].
