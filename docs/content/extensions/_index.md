Architect ships the extension runtime, not extensions of its own: the
features an app offers are extensions it links in or installs (Studio's,
for instance, are in `studio:extensions`). Writing one:
[Writing an extension](@/extensions/authoring.md) walks through every
runtime, the manifest, the host API, install and testing, and links to the
rest ([Extensions](@/architecture/extensions.md) is the design).
