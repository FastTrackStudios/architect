Added extension blocks on the node's share links and Sites (#488): `architect_sites::InstalledBlocks` draws the fences of the extensions installed in `ARCHITECT_EXTENSIONS` (`<data dir>/extensions`), embed pages and, with feature `wasi` (`architect-desktop` `node-wasi`), a WASI component's embed view (`ComponentBlocks`; the guest reads its input with `architect_extension_wasi::embed()`), ahead of a distribution's or an embedder's `Blocks`; `Blocks` is a `BlockRenderer` (`claims`, `drawn_by`). Security: what any renderer draws is sanitised by allow-lists (`architect_sites::sanitize`; an element tree goes through it too): SVG drawing elements inside an `<svg>` and basic HTML outside (text, lists, tables, links, images, `<audio>`/`<video>`, `<details>`, `<button type="button">`), their geometry and presentation attributes, `class`, `title`, `lang`, `dir`, `role`, `aria-*`, `data-*` and `id` (not the page's own: `site-*`, `share-*`, `comments`, `data-site-*`, `data-act`), and URLs only relative, `#…`, `https:`, `mailto:` (links) and raster `data:` images, every decision made on decoded values; no form fields, SMIL animation, `<foreignObject>`, `on…`, `srcset` or `ping`; CSS checked bluntly: a sheet, `style` value or presentation attribute holding a quote, comment, escape, `var()`, custom property or at-rule is refused before anything else, then anything that loads (`url(`, `image-set(`, `paint(`, …; a presentation attribute only `url(#id)`) and any `position` but `static`/`relative`; a block's images only relative or raster `data:`; ids shadowing the page script's globals (`architect`, …) reserved. The site wraps every block in a box of its own class and style (`BLOCK_BOX_STYLE`: `contain`, `overflow: auto`, `position: relative`, `isolation`), and a block's SVG `<style>` sheet is kept only as flat rules put under that class (`Block::scope`, `architect_sites::sanitize_block`, `Drawn::into_block_html`); plain `sanitize` keeps no sheet. Every share and Site page the node serves carries a Content-Security-Policy (`script-src 'self'` plus the site's theme script by hash, `form-action 'self'`, `object-src 'none'`, `base-uri 'none'`); a page's live reload is now read from `<meta name="site-live">` by the site's script, not an inline script; the player reads its queue only from `script#site-queue[type="application/json"]`. API: `elements_to_html` and `Drawn::into_html` return `Result` (a tree past 100,000 elements or 16 MiB is refused). A component's edits can no longer put one node in two places or build a tree deeper than 256 levels, and its drawing is bounded as it is written (50,000 nodes, 16 MiB, the deadline checked). The share player follows SVG `[data-at]` elements, scrolls the nearest scrolling box by bounding rect and fills the current SVG bar from the theme. Bounds: `sanitize` is linear in its input on any input (at most 256 elements open), an element tree is written to 256 levels, and a component's drawing holds at most 50,000 nodes and 16 MiB.
