Toolbars as a first-class system, and context-menu entries, as extension contributions with live toggle and armed state (#307; modelled on Fergler Advanced Toolbars, design only). A toolbar is a document (`toolbar::ToolbarDecl`): `where` (`dock:left|right|bottom`, `float`, `window`, `pane`, `view:<kind>`) and items of one flat type (`ToolItem`): buttons (an action, a label and/or icon, theme-token colours for normal, on and armed, a `right_click` of `menu`, `arm`, `none` or another action), separators, groups (joined, labelled), dropdowns (`MenuItem`: actions ticked live, headings, separators, nested submenus), widgets (an extension's view as a live control) and `newline` rows. Extensions ship them in `[[toolbars]]`; a person's `toolbars/*.toml` (`Toolbars::set_dir`, hot-reloaded) adds their own or overrides one by key; `TOOLBAR_LIST/GET/SAVE/RESET/ARM/DISARM` read and write them for an editor (#313 builds it). A pane toolbar is a headless workspace view opened in its dock, floating, or in a window of its own; a header toolbar draws through `architect_workspace::HeaderTools`; a press runs with the new `InvocationSource::Toolbar`. An action declares `toggle = true` and says whether it is on with runtime state of kind `checked` (every extension kind alike); its buttons, ⌘K, the menu bar's contributed rows and context menus follow it live. `[[context]]` rows now reach a tab's menu (`target = "tab"`) and a view's own targets through `PaneHandle::context_menu` (the lab's file tree: `file`, `file:<ext>`), run with `context_invocation`. A bad toolbar refuses the load with a problem `APP_STATUS` lists; a bad person's file is a problem, the rest load. A right-press on a tab no longer starts a drag. The guide's `@click{secondary true}` right-clicks, and the headless runner waits for an async check. The lab's metronome has a click toggle on a toolbar in the right dock (armed by a right-click, a group with a dropdown), in every note's header, and in tab and Markdown-file context menus. API breaks (pre-1.0): `ContextEntry` gained `checked`, `Do::Click` gained `secondary`, `Contribution` gained `toolbars`, `ActionDecl` gained `toggle`, `StateKind` gained `Checked`, `Host` gained `toolbars`.
