Added the fleet feature union: every crate depends on `architect-workspace-hack` (cargo-hakari plus the new `cargo xtask fleet-deps`), which turns on the features Task, studio, keyflow and frame build the shared third-party crates with (Dioxus `web`, `mobile` and `fullstack`, tokio `tracing`, reqwest, tokio-rustls `aws-lc-rs`, …). A consumer then builds those crates with architect's features and versions, and kache shares one build across the fleet. Off on wasm.

Migration: a consumer aligns its `[patch]` tags with architect's (vendor `v0.7.1`); otherwise its graph gets a second copy of each patched crate. Its `Cargo.lock` moves up to architect's locked versions of the shared crates (`cargo update -p <crate> --precise <architect's version>`).
