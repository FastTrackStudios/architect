Added an editor API for extensions (#312). Through the host service an extension reads the editor the person is typing in (`editor_state`: its text, selection, cursor and the markdown node at the cursor, a list item or a table cell and its table's cells among them), edits it as one transaction and one undo step made as the extension (`edit_editor`, refused when stale or out of bounds), and decorates it (`decorate_editor`: marks, line classes, gutter markers and widgets that mount one of its own embeds, `embeds::WidgetView`). The values are the editor repository's `editor-ext` (`editor_ext::Snapshot`, `EditCommand`, `DecorationSpec`, re-exported from `architect_extensions::editor`). From Luau (`host.editor`, `host.edit_editor`, `host.decorate_editor`), pages (`editor.state`, `editor.edit`, `editor.decorate`), the WIT world's typed imports and the wasi guest's `host::editor_state`, …. A manifest declares `[[keymaps]]` (a key, its action, `when = "editor"` or `"node:<kind>"`) and `[[slash]]` rows; both need the new `editor` capability, `writes = ["editor"]` (`reads = ["editor"]` only reads), on the consent screen. An app implements `editor::Editors` and passes it to `Host::with_editors`; `editor::MemoryEditor` is one over a string. The lab's Vault note now edits in the FastTrackStudios editor, and `lab.outline` (`apps/lab/extensions/outline`, `ARCHITECT_LAB_OUTLINE=1`) gives it Tab and Shift-Tab in lists and tables, marks and a count widget, and a slash row for a table. API breaks: `HostRequest` has three new variants, `Contribution` has `keymaps` and `slash`, `contrib::Rules` has `writes`, `capabilities::READS` and `WRITES` gained `editor`, and the WIT host interface has three new imports. Needs the editor at its extension-API branch (`editor-ext`, and `editor-view`'s `history`, `on_key`, `mounts`, `on_action`).
