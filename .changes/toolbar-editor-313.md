A visual toolbar editor (#313; modelled on Fergler Advanced Toolbars' edit mode, design only). **Edit toolbars** (`TOOLBAR_EDIT`, or a toolbar's context menu) shows + chips between items (an action, a separator, a widget or a dropdown), a ⚙ for the toolbar's settings, and makes items draggable: buttons into and out of groups, whole groups, into another toolbar on show, Escape cancelling. The action picker uses the palette's search (`architect_commands::rank`); the widget picker lists views by extension with a live preview. Item settings: label, Lucide icon or an image file (`ToolItem::image`), label visibility, colours as theme tokens, right-click, dropdown rows, widget width, new row. Toolbar settings: title, place, size, spacing, rounding, labels (`ToolbarStyle`), colour presets (`PRESETS`), a context (`ToolbarDecl::when`), which toolbar a place shows (`Toolbars::show`, `where = "hidden"`), duplicate, delete. Edits (`Toolbars::edit` with `toolbar_edit`'s operations, items by place `At`) show at once, are written `DEBOUNCE` after the last, and keep the last `BACKUPS` of each file in `.backups/`. Every edit is a `TOOLBAR_*` action: `NEW`, `RENAME`, `DUPLICATE`, `DELETE`, `SHOW`, `INSERT`, `REMOVE`, `MOVE`, `SET`, `GROUP`, `UNGROUP`, `SELECT`, `BACKUPS`, `EDIT`; from an item's context menu they need no arguments. Also: dropdowns near the window's edge move to stay in it (`toolbar_editor::Kept`); context-menu targets are contribution points their features declare (`Host::declare_context_targets`, `contrib::context_point`; `architect_workspace::CONTEXT_TARGETS`), each `[[context]]` row an item of its target's point; a badged tab in a narrow bar keeps its badge and some of its name; extensions' prompts, dialogs and toasts are over a tour's card (`host_ui_view::PROMPT_LAYER`, `tour::TOUR_LAYER`); the workspace's "Open …" commands follow views that come and go; a scenario's `@drag` can press a key before letting go (`key Escape`). The lab's Board has a tempo widget (`lab.board/tempo`). API breaks (pre-1.0): `contrib::TARGETS` is gone (`known_target` checks a name); `TabBadges` returns `Option<Element>`; `ToolbarDecl` gained `style` and `when`, `ToolItem` gained `image`, `ToolbarPlace` gained `Hidden`; `Do::Drag` gained `key`; `Toolbars::reset` keeps a backup.
